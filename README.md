# 럭키드로우 원판 추첨

참가자와 경품을 입력하면 "경품 칸 + 꽝 1칸"으로 된 원판을 만들고, 한 사람씩 돌려 당첨과 꽝을 가르는 웹페이지입니다. 서버와 빌드 과정 없이 HTML·CSS·JS 파일만으로 동작합니다.

화면은 **설정 → 추첨 → 결과** 세 개입니다.

## 실행 방법

### 브라우저에서 열기

`index.html`을 브라우저로 열면 바로 동작합니다. 설치할 패키지가 없습니다.

클립보드 복사까지 확실히 쓰려면 로컬 서버로 여는 편이 안전합니다.

```bash
python3 -m http.server 8000
# 또는
npx serve .
```

그다음 `http://localhost:8000`에 접속합니다.

### 셀프테스트

Node.js 18 이상이 필요합니다.

```bash
node selftest.mjs
```

DOM 없이 원판 핵심 로직 세 가지를 검사합니다.

| 항목 | 내용 | 요구사항 |
|---|---|---|
| 공정성 | 4칸 원판 10,000회에서 각 칸이 22~28% 안에 듭니다 | T-10 |
| 바늘-결과 일치 | 2~30칸 원판 1,000회에서 멈춤 각도가 항상 고른 칸 안에 있습니다 | T-09 |
| 글자 대비 | 칸 색 팔레트 전체에서 글자 대비가 4.5:1 이상입니다 | 10장 |

## 사용 방법

1. **설정**: 참가자를 이름 목록(줄바꿈·쉼표 구분) 또는 인원수(1~500명)로 입력합니다. 경품은 한 줄에 하나씩 쓰고, 수량은 `커피 쿠폰 x3`처럼 뒤에 붙입니다.
2. **추첨**: "돌리기" 버튼, 스페이스바, 원판 클릭 중 하나로 원판을 돌립니다. 결과를 확인한 뒤 "다음 사람"을 눌러 넘어갑니다.
3. **결과**: 경품이 모두 나가거나 참가자가 모두 탈락하면 결과 화면으로 넘어갑니다. 당첨자 명단을 CSV로 받거나 클립보드로 복사할 수 있습니다.

## 추첨 규칙

- 경품 1개가 원판 1칸입니다. 꽝 칸은 항상 1개이고, 전체 칸 수(경품 합계 + 1)는 최대 30칸입니다.
- 바퀴마다 남은 참가자를 무작위로 섞어 순서를 정합니다. 같은 바퀴에서 같은 사람은 두 번 돌리지 않습니다.
- 당첨이든 꽝이든 돌린 사람은 바로 탈락합니다. 꽝으로 탈락한 사람은 결과 화면의 "경품을 못 받은 참가자" 목록에 남습니다.
- 당첨되면 그 경품 칸 1개가 빠지고, 남은 칸을 다시 섞어 같은 크기로 나눕니다.
- 결과는 회전 **전에** `crypto.getRandomValues`로 정하고, 원판은 그 칸에 맞춰 멈춥니다. 멈추는 위치는 칸 가장자리 10%를 뺀 범위라 경계선에 걸리지 않습니다.
- "방금 결과 취소"로 직전 한 번의 결과를 되돌릴 수 있습니다.
- 진행 상태는 localStorage에 저장되어 새로고침해도 이어집니다. 저장을 못 쓰는 환경에서도 추첨은 정상 동작합니다.
- 운영체제에서 "동작 줄이기"(`prefers-reduced-motion`)를 켜면 회전 시간이 4~6초에서 0.5초로 줄어듭니다.
